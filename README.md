# Mon Petit Journal 🌸

Une application Android de journal intime personnel avec un compagnon virtuel personnalisable.

## Fonctionnalités
- Écrire et consulter ses entrées de journal.
- Choisir son humeur.
- Personnaliser le nom et la personnalité du compagnon.
- Choisir parmi plusieurs thèmes visuels.
- Recevoir des encouragements adaptés au contenu écrit.

## Compilation
Le projet utilise Kotlin, Jetpack Compose et Material 3.

Le workflow GitHub Actions permet de compiler l'application et de générer un APK de débogage.

## Remarque
Les réponses du compagnon sont générées par un système local basé sur des mots-clés. Il ne s'agit pas encore d'une véritable IA conversationnelle.
